# Core Python packages
requests>=2.31.0
urllib3>=2.0.0

# HTTP client. Both chatbots do "import httpx" at module scope and build an
# httpx.Client(http2=True), so httpx and its http2 extra are hard requirements,
# not optional. They were previously missing here, which meant a clean install
# failed with ModuleNotFoundError on the very first run.
httpx[http2]>=0.25.0

# Azure OpenAI integration
# Capped below 3.0 on purpose: openai 3.x switched its http_client parameter
# from httpx.Client to httpx2.Client, which breaks the AzureOpenAI(...) calls
# in both chatbots. Lift this cap only together with a port to httpx2.
openai>=1.35.0,<3

# Palo Alto Networks AI Runtime Security SDK
# Published on public PyPI as "pan-aisecurity". The importable module is
